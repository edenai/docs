Use the `/v3/info` endpoints to discover all available expert model features, providers, and models.

## Endpoints

| Endpoint | Description |
|----------|-------------|
| `GET /v3/info` | List all features and subfeatures |
| `GET /v3/info/{feature}/{subfeature}` | Get providers, models, pricing, and schemas for a specific feature |
| `GET /v3/info/audio/tts/voices` | Discover accepted text to speech voices with optional filtering |

## List All Features

<CodeGroup>
```bash cURL
curl https://api.edenai.run/v3/info \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.edenai.run/v3/info",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

for feature in response.json()["features"]:
    print(feature["name"])
```

```javascript JavaScript
const response = await fetch("https://api.edenai.run/v3/info", {
  headers: { "Authorization": "Bearer YOUR_API_KEY" }
});

const { features } = await response.json();
features.forEach(f => console.log(f.name));
```
</CodeGroup>

## Get Feature Details

Retrieve providers, pricing, and input/output schemas for a specific feature.

<CodeGroup>
```bash cURL
curl https://api.edenai.run/v3/info/text/moderation \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.edenai.run/v3/info/text/moderation",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)

details = response.json()
for model in details.get("models", []):
    print(model["model"], model["pricing"])
```
</CodeGroup>

## List Text to Speech Voices

Discover voices accepted by Universal AI `audio/tts` models:

<CodeGroup>
```bash cURL
curl "https://api.edenai.run/v3/info/audio/tts/voices?model=audio/tts/google/wavenet&language=en-US" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.edenai.run/v3/info/audio/tts/voices",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"model": "audio/tts/google/wavenet", "language": "en-US"},
)

for voice in response.json()["data"]:
    print(voice["id"], voice["name"], voice["gender"])
```

```javascript JavaScript
const response = await fetch(
  "https://api.edenai.run/v3/info/audio/tts/voices?model=audio/tts/google/wavenet&language=en-US",
  {
    headers: { "Authorization": "Bearer YOUR_API_KEY" }
  }
);

const { data } = await response.json();
data.forEach(voice => console.log(voice.id, voice.name, voice.gender));
```
</CodeGroup>

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `model` | string | Restrict to one model, such as `audio/tts/google/wavenet` |
| `language` | string | Filter by BCP-47 language tag, such as `en-US` |
| `gender` | string | Filter by voice gender: `male`, `female`, or `unknown` |

## Response Fields

| Field | Description |
|-------|-------------|
| `models` | Available providers and model strings |
| `pricing` | Cost per provider |
| `input_schema` | Parameters accepted by this feature |
| `output_schema` | Structure of the response |
