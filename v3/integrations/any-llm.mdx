any-llm is Mozilla AI's Python library with one `completion()` call for every provider. Eden AI is a built-in provider (`edenai`), so a single `EDENAI_API_KEY` reaches the whole catalog.

## Overview

[any-llm](https://github.com/mozilla-ai/any-llm) lets you talk to any LLM provider through a single `completion()` interface, so you swap providers by changing one string. You reach models from OpenAI, Anthropic, Google, Mistral and 500+ more behind one key.

You select a model with the `provider:model_id` syntax. For Eden AI, the provider is `edenai` and the model id follows Eden AI's `provider/model` scheme, for example `edenai:anthropic/claude-sonnet-latest`. Use the colon form: any-llm deprecates the older slash form, where the provider is separated from the model by `/`.

## Installation

Install any-llm with the Eden AI provider extra:

<CodeGroup>
```bash pip
pip install 'any-llm-sdk[edenai]'
```

```bash uv
uv add 'any-llm-sdk[edenai]'
```
</CodeGroup>

## Quick Start

Set your key, then point any-llm at Eden AI by prefixing any model with `edenai:`:

<CodeGroup>
```bash .env
EDENAI_API_KEY=YOUR_API_KEY
```

```python Python
from any_llm import completion

response = completion(
    model="edenai:vertex/gemini-flash-latest",  # edenai:<provider>/<model>
    messages=[{"role": "user", "content": "Hello! How are you?"}],
)

print(response.choices[0].message.content)
```
</CodeGroup>

The `edenai` provider automatically uses the Eden AI base URL (`https://api.edenai.run/v3`) and reads your key from the `EDENAI_API_KEY` environment variable.

## Model naming

Use `edenai:<provider>/<model>`. any-llm splits on the first colon, so the rest is passed to Eden AI unchanged: for example `edenai:anthropic/claude-sonnet-latest` or `edenai:mistral/mistral-small-latest`. To browse every id, see [List LLM Models](/v3/llms/listing-models).

## Switching models

any-llm's core benefit: change providers by changing one string. Every Eden AI model is reachable the same way:

<CodeGroup>
```python Python
from any_llm import completion

messages = [{"role": "user", "content": "Write a haiku about the sea."}]

for model in [
    "edenai:openai/gpt-latest",
    "edenai:anthropic/claude-sonnet-latest",
    "edenai:mistral/mistral-large-latest",
]:
    response = completion(model=model, messages=messages)
    print(model, "->", response.choices[0].message.content)
```
</CodeGroup>

## Streaming

Eden AI supports streaming through any-llm. Pass `stream=True`:

<CodeGroup>
```python Python
from any_llm import completion

stream = completion(
    model="edenai:mistral/mistral-small-latest",
    messages=[{"role": "user", "content": "Count from one to five."}],
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)
```
</CodeGroup>

## Embeddings

The Eden AI provider also supports embeddings. `inputs` takes a string or a list of strings:

<CodeGroup>
```python Python
from any_llm import embedding

response = embedding(
    model="edenai:openai/text-embedding-3-small",
    inputs="The quick brown fox jumps over the lazy dog.",
)

print(response.data[0].embedding[:5])
```
</CodeGroup>
