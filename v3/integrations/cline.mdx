Cline talks to any OpenAI-compatible endpoint, so Eden AI needs no extension or plugin: you enter a base URL, a key and a model ID. Cline sends tool definitions with every request, so pick a model that supports function calling.

## Overview

[Cline](https://github.com/cline/cline) is a VS Code extension that gives you an autonomous coding agent: it creates files, runs terminal commands and completes multi-step tasks. Pointed at Eden AI's OpenAI-compatible endpoint, it can use 500+ models from OpenAI, Anthropic, Google and more with one API key, and you switch models without leaving VS Code.

## Prerequisites

- [VS Code](https://code.visualstudio.com) installed
- [Cline](https://docs.cline.bot/getting-started/installing-cline) installed in VS Code
- Eden AI API key from [https://app.edenai.run](https://app.edenai.run)

## Setup

### Step 1: Open Cline

1. Click the **Cline icon** in the VS Code activity bar.
2. On the onboarding screen, select **Bring my own API key** ("Use Cline with your provider of choice") and click **Continue**.

Already set up? Click the settings icon in the Cline panel and use the **API Provider** dropdown there.

### Step 2: Configure your provider

In the API Provider dropdown, select **"OpenAI Compatible"**.

Fill in the following fields:

| Field | Value |
|---|---|
| **Base URL** | `https://api.edenai.run/v3` |
| **API Key** | Your Eden AI API key |
| **Model ID** | e.g. `anthropic/claude-sonnet-latest` |

Click **Continue**.

## Model naming

Cline sends the Model ID as you write it, so use the full `provider/model` id. Aliases ending in `-latest` follow the newest model of a family. Examples that support function calling:

- `anthropic/claude-sonnet-latest`
- `vertex/gemini-flash-latest`
- `openai/gpt-mini-latest`

List the available models, with their capabilities and pricing, in [Listing models](/v3/llms/listing-models).

## Switching models

Open the Cline settings and change the **Model ID** under the **OpenAI Compatible** provider. Settings apply as you edit; click **Done** to close the view. The Base URL and API key stay the same.

## Expert Models as Tools (MCP)

Eden AI also hosts an [MCP server](/v3/expert-models/mcp-server) that exposes the expert model catalog (OCR, web search, speech, translation and more) as tools. Click the **MCP Servers** icon in the Cline panel toolbar, open the **Configure** tab, and click **Configure MCP Servers**. This opens `cline_mcp_settings.json`; add the server under `mcpServers`:

```json
{
  "mcpServers": {
    "edenai": {
      "type": "streamableHttp",
      "url": "https://mcp.edenai.run/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

See the [MCP server page](/v3/expert-models/mcp-server) for the full tool catalog and the conventions its tools share.

## Troubleshooting

### Authentication Errors (401)

1. Confirm your Eden AI API key is correct: copy it from [app.edenai.run](https://app.edenai.run) under **API Keys**.
2. Make sure there are no leading or trailing spaces in the key.
3. A 401 with `Invalid API key` means the `sk-eden-...` key is wrong or revoked; `Invalid token` means the credential is not an Eden AI key at all.

### Connection Issues

1. Verify the base URL is exactly: `https://api.edenai.run/v3`
2. Check Eden AI status: [https://app-edenai.instatus.com](https://app-edenai.instatus.com)

### The agent ignores edits or fails to call tools

Cline sends tool definitions with every request. Choose a model that supports function calling, such as the ones under [Model naming](#model-naming).
