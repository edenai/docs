Kilo Code reads Eden AI as its `edenai` provider. This page sets it up in the extension and the CLI, then covers models missing from the picker, EU routing, MCP tools and cost.

## Overview

Kilo Code is an open-source coding agent for VS Code and the terminal. Eden AI is a provider in both the extension and the CLI: Kilo takes the `edenai` provider from the [models.dev](https://models.dev) catalogue, an OpenAI-compatible provider at `https://api.edenai.run/v3`, and reads your key from `EDENAI_API_KEY`.

- **Shared credential store**: the extension and the CLI read the same `auth.json`
- **EU endpoint**: route through the [EU endpoint](/v3/data-governance/eu-endpoint) when you have data-residency requirements

## Prerequisites

- Kilo Code installed, either the VS Code extension or the CLI. See [kilocode.ai](https://kilocode.ai)
- An Eden AI API key from [app.edenai.run](https://app.edenai.run) → **API Keys**

## Setup in VS Code

1. Open **Settings** in the Kilo Code extension.
2. Go to the **Providers** tab and add **Eden AI**. If it is not listed, click **Show more providers**.
3. Paste your Eden AI API key.
4. Select a model.

Credentials are stored in Kilo's `auth.json`, the same store the CLI uses.

## Setup in the CLI

Connecting interactively is the recommended path, so the key lands in `auth.json` rather than in a project file. In the TUI run `/connect`, choose **Eden AI**, then paste your key. From the shell:

<CodeGroup>
```bash Terminal
kilo auth login --provider edenai
```
</CodeGroup>

Then pick a model from the picker, or set a default:

<CodeGroup>
```json kilo.json
{
  "model": "edenai/vertex/gemini-flash-latest"
}
```
</CodeGroup>

To keep the secret in the environment instead, declare the provider in `~/.config/kilo/kilo.json` or `./kilo.json`:

<CodeGroup>
```bash Terminal
export EDENAI_API_KEY="YOUR_API_KEY"
```

```json ~/.config/kilo/kilo.json
{
  "provider": {
    "edenai": {
      "env": ["EDENAI_API_KEY"]
    }
  },
  "model": "edenai/vertex/gemini-flash-latest"
}
```
</CodeGroup>

## Model naming

Eden AI model IDs are already `vendor/model`, so a full reference in Kilo has **three** segments, `edenai/<vendor>/<model>`:

{/* skip-test: one-line examples of a single key, not a whole config file */}
<CodeGroup>
```json Examples
{ "model": "edenai/openai/gpt-mini-latest" }
{ "model": "edenai/vertex/gemini-flash-latest" }
{ "model": "edenai/zai/glm-5.2" }
```
</CodeGroup>

Kilo Code takes its model list from models.dev, not from Eden AI's [models endpoint](/v3/llms/listing-models). Copy the identifier exactly as the endpoint returns it, which is public and needs no key:

<CodeGroup>
```bash cURL
curl https://api.edenai.run/v3/models
```
</CodeGroup>

## Switching models

Pick another model in the picker, or change the `model` key in `kilo.json` to another `edenai/<vendor>/<model>` reference.

## Using a model that is not in the picker

The picker lists the Eden AI models in models.dev, which is smaller than the full Eden AI catalogue. Any other model can be declared yourself. `mistral/devstral-latest`, a coding model that supports function calling, is one that models.dev does not list today:

<CodeGroup>
```json kilo.json
{
  "provider": {
    "edenai": {
      "models": {
        "mistral/devstral-latest": {
          "name": "Devstral (latest)",
          "cost": { "input": 0.4, "output": 2 }
        }
      }
    }
  },
  "model": "edenai/mistral/devstral-latest"
}
```
</CodeGroup>

<Note>
  Set `cost` when you declare a model, and `limit` too if you want the context gauge to be right. Kilo defaults both to zero for a model it does not already know, which would leave spend reporting at zero. Costs are per million tokens, so multiply `pricing.input_cost_per_token` and `pricing.output_cost_per_token` from the models endpoint by one million (the values above are the catalogue's rates for this alias today). A `limit` block needs both `context`, from `context_length`, and `output`, the model's maximum output tokens, which the endpoint does not list.
</Note>

## EU data residency

Point the provider at the [EU endpoint](/v3/data-governance/eu-endpoint) with a custom base URL, and choose a model the EU endpoint serves. The EU endpoint serves a subset of the catalogue (`vertex/gemini-flash-latest` and `mistral/mistral-small-latest` are in it), and Eden AI rejects a model it does not serve, such as `anthropic/claude-sonnet-latest` or `openai/gpt-mini-latest`:

<CodeGroup>
```json kilo.json
{
  "provider": {
    "edenai": {
      "env": ["EDENAI_API_KEY"],
      "options": {
        "baseURL": "https://api.eu.edenai.run/v3"
      }
    }
  },
  "model": "edenai/vertex/gemini-flash-latest"
}
```
</CodeGroup>

Some models are also published with an `@eu` suffix that pins the vendor's region; see [Pinning a region](/v3/llms/provider-routing#pinning-a-region). Declare those as shown in the previous section.

## Expert Models as Tools (MCP)

Eden AI also hosts an [MCP server](/v3/expert-models/mcp-server) that exposes the expert model catalog (OCR, web search, speech, translation and more) as tools. Kilo reads MCP servers from the `mcp` key of its config. Add the server to the global `~/.config/kilo/kilo.json`, where credentials belong:

<CodeGroup>
```json ~/.config/kilo/kilo.json
{
  "mcp": {
    "edenai": {
      "type": "remote",
      "url": "https://mcp.edenai.run/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```
</CodeGroup>

Run `kilo mcp list` to check the connection. See the [MCP server page](/v3/expert-models/mcp-server) for the tool catalog and the conventions its tools share.

## Cost tracking

The spend Kilo Code displays for Eden AI is derived from token counts and the per-model rates in its catalogue, so treat it as an estimate. Eden AI returns the actual billed cost of each request in a top-level `cost` field of the response (see [Prompt caching](/v3/llms/prompt-caching)), and that figure is the authoritative one.

## Troubleshooting

### Invalid API key

Create a new key in your Eden AI account (a 401 with `Invalid API key` means the key is wrong or revoked, `Invalid token` that the credential is not an Eden AI key), then reconnect with `/connect` or `kilo auth login --provider edenai`. If you use manual configuration, update `EDENAI_API_KEY` in the environment Kilo runs from.

### Model not found

Copy the identifier exactly as the [models endpoint](https://api.edenai.run/v3/models) returns it, vendor prefix included. Do not rely on a static list.

### Eden AI is not visible in the provider list

Refresh Kilo Code's provider catalogue, then check **Show more providers**.

### A key or model you just added has no effect

A key or a model you declared in `kilo.json` needs a restart of Kilo. A model newly added to models.dev shows up in the picker within about an hour, since Kilo refreshes that catalogue hourly.
