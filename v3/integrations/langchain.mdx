Eden AI's `/v3` endpoint is OpenAI-compatible, so LangChain's `ChatOpenAI` talks to it once you change `base_url` and the model id. Every chat model in the catalog is then available through the same LangChain chat model interface, in Python and in TypeScript.

## Overview

[LangChain](https://langchain.com) is a framework for developing applications powered by language models. LangChain's `ChatOpenAI` class (`langchain-openai` for Python, `@langchain/openai` for TypeScript) sends OpenAI-style chat completion requests to any base URL you give it, and Eden AI's `/v3/chat/completions` accepts them.

## Installation

Python needs 3.10 or later, and the TypeScript package needs Node.js 22 or later.

<CodeGroup>
```bash Python
pip install langchain-openai python-dotenv
```

```bash TypeScript
npm install @langchain/openai @langchain/core
```

</CodeGroup>

## Quick Start

<CodeGroup>
```python Python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

llm = ChatOpenAI(
    model="openai/gpt-latest",
    api_key="YOUR_API_KEY",
    base_url="https://api.edenai.run/v3"
)

messages = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="What is LangChain?")
]

response = llm.invoke(messages)
print(response.content)
```

```typescript TypeScript
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

const llm = new ChatOpenAI({
  model: "openai/gpt-latest",
  apiKey: "YOUR_API_KEY",
  configuration: {
    baseURL: "https://api.edenai.run/v3",
  },
});

const messages = [
  new SystemMessage("You are a helpful assistant."),
  new HumanMessage("What is LangChain?"),
];

const response = await llm.invoke(messages);
console.log(response.content);
```

</CodeGroup>

The TypeScript sample uses top-level `await`, so run it as an ES module: save it as a `.mts` file, or set `"type": "module"` in `package.json`.

## Model naming

Pass any `provider/model` id as `model`, for example `openai/gpt-latest`, `anthropic/claude-sonnet-latest` or `vertex/gemini-flash-latest`. Browse the catalog in [List LLM Models](/v3/llms/listing-models).

## Environment Variables

<CodeGroup>
```bash .env
EDEN_AI_API_KEY=your_api_key_here
```

```python Python
import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(
    model="openai/gpt-latest",
    api_key=os.getenv("EDEN_AI_API_KEY"),
    base_url="https://api.edenai.run/v3"
)
```
