By the end of this page, an `edenai` provider shows up in Pi's `/model` picker, and you can run Pi on any Eden AI chat model that supports function calling.

## Overview

Pi is an MIT-licensed coding agent that runs in your terminal. It reads custom providers from a `models.json` file, so Eden AI's OpenAI-compatible endpoint needs a config entry and no code. Pi sends tool definitions with every request, so choose models that support function calling.

## Prerequisites

- Node.js 22.19 or newer (Pi's installers can install it for you)
- An Eden AI API key from [app.edenai.run](https://app.edenai.run)

## Setup

### Step 1: Install Pi

<CodeGroup>
```bash Install script
curl -fsSL https://pi.dev/install.sh | sh
```

```bash npm
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```
</CodeGroup>

### Step 2: Export your key

Pi resolves `$EDEN_AI_API_KEY` from the environment of the shell that starts it. It does not read a `.env` file.

<CodeGroup>
```bash Terminal
export EDEN_AI_API_KEY="YOUR_API_KEY"
```
</CodeGroup>

### Step 3: Add the provider

Create or edit `~/.pi/agent/models.json` (Pi looks for it in its agent directory, which you can move with `PI_CODING_AGENT_DIR`):

<CodeGroup>
```json ~/.pi/agent/models.json
{
  "$schema": "https://pi.dev/schemas/models.schema.json",
  "providers": {
    "edenai": {
      "name": "Eden AI",
      "baseUrl": "https://api.edenai.run/v3",
      "api": "openai-completions",
      "apiKey": "$EDEN_AI_API_KEY",
      "models": [
        { "id": "openai/gpt-latest" },
        { "id": "anthropic/claude-sonnet-latest" },
        { "id": "mistral/mistral-small-latest" }
      ]
    }
  }
}
```
</CodeGroup>

Only `id` is required for each model. Pi assumes text input, no reasoning, a 128,000-token context window and 16,384 output tokens unless you set `input`, `reasoning`, `contextWindow` or `maxTokens` on the model. Opening `/model` reloads the file.

## Model naming

The provider is `edenai`, and each model `id` is the Eden AI `provider/model` id, so Pi refers to a model as `edenai/<provider>/<model>`, for example `edenai/anthropic/claude-sonnet-latest` or `edenai/openai/gpt-latest`. Aliases ending in `-latest` follow the newest model of a family. Browse the available ids and their capabilities in [Listing models](/v3/llms/listing-models).

## Switching models

Run `/model` in Pi and choose an Eden AI model, press `Ctrl+P` to cycle through your models, or pass one when you start Pi:

<CodeGroup>
```bash Terminal
pi --model edenai/anthropic/claude-sonnet-latest
```
</CodeGroup>

## Expert Models as Tools (MCP)

Pi connects to MCP servers, so Eden AI's [MCP server](/v3/expert-models/mcp-server) can give it OCR, web search, speech and translation tools. Add it to `~/.pi/agent/mcp.json`, where credentials belong:

<CodeGroup>
```json ~/.pi/agent/mcp.json
{
  "mcpServers": {
    "edenai": {
      "url": "https://mcp.edenai.run/mcp",
      "headers": { "Authorization": "Bearer ${EDEN_AI_API_KEY}" }
    }
  }
}
```
</CodeGroup>

Pi selects streamable HTTP from the `url`. Run `pi mcp list` to check the connection, and see the [MCP server page](/v3/expert-models/mcp-server) for the tool catalog.

## Troubleshooting

### Eden AI is missing from `/model`

The picker shows only models whose provider has usable authentication. Check that `EDEN_AI_API_KEY` is exported in the shell you start Pi from, then open `/model` again to reload `models.json`. `pi --list-models edenai` lists what Pi found.

### Authentication errors (401)

Confirm the key at [app.edenai.run](https://app.edenai.run) under **API Keys**, and that it has no leading or trailing spaces. A 401 with `Invalid API key` means the `sk-eden-...` key is wrong or revoked; `Invalid token` means the credential is not an Eden AI key at all.

### The agent fails when it tries to use tools

Use a model that supports function calling. The ids on this page do.
