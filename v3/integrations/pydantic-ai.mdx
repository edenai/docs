Pydantic AI has no Eden AI provider, so you connect it through its OpenAI-compatible classes. This page shows the setup, structured output, message history and error handling.

## Overview

Pydantic AI is a type-safe, structured-output agent framework for Python. It works with any OpenAI-compatible endpoint through `OpenAIChatModel` and `OpenAIProvider`, so you can point it at Eden AI's V3 API and use models from OpenAI, Anthropic, Google, Cohere, Meta and more behind one key.

## Installation

Pydantic AI requires Python 3.11 or later.

<CodeGroup>
```bash pip
pip install pydantic-ai
```

```bash poetry
poetry add pydantic-ai
```

</CodeGroup>

## Quick Start

Point Pydantic AI's OpenAI model at Eden AI:

<CodeGroup>
```python Python
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "openai/gpt-latest",
    provider=OpenAIProvider(
        api_key="YOUR_API_KEY",  # Get from https://app.edenai.run
        base_url="https://api.edenai.run/v3",
    ),
)

agent = Agent(model)
result = agent.run_sync("Hello! How are you?")
print(result.output)
```
</CodeGroup>

## Model naming

Models use the `provider/model` format, for example `openai/gpt-latest`, `anthropic/claude-sonnet-latest` and `vertex/gemini-flash-latest`. Pass the id as the first argument of `OpenAIChatModel`. See [List LLM Models](/v3/llms/listing-models) for the full catalog.

## Structured Output

Define a Pydantic `output_type` and the agent returns a validated object. By default Pydantic AI asks for the object through a tool call, so choose a model whose catalog entry has `supports_function_calling` (see [List LLM Models](/v3/llms/listing-models)):

<CodeGroup>
{/* paid-test: needs a real model answer, the sandbox returns canned prose */}
```python Python
from pydantic import BaseModel
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

class City(BaseModel):
    name: str
    country: str
    population: int

model = OpenAIChatModel(
    "anthropic/claude-sonnet-latest",
    provider=OpenAIProvider(
        api_key="YOUR_API_KEY",
        base_url="https://api.edenai.run/v3",
    ),
)

agent = Agent(model, output_type=City)
result = agent.run_sync("Tell me about the capital of France.")
print(result.output)  # City(name='Paris', country='France', population=...)
```
</CodeGroup>

## Multi-Turn Conversations

Keep conversation history across runs with `message_history`:

<CodeGroup>
```python Python
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "anthropic/claude-sonnet-latest",
    provider=OpenAIProvider(
        api_key="YOUR_API_KEY",
        base_url="https://api.edenai.run/v3",
    ),
)
agent = Agent(model, system_prompt="You are a helpful assistant.")

result = agent.run_sync("What is the capital of France?")
print(result.output)

# Continue the conversation with prior context
result = agent.run_sync(
    "What's its population?",
    message_history=result.all_messages(),
)
print(result.output)
```
</CodeGroup>

## Error Handling

Every 4xx or 5xx answer from Eden AI raises `ModelHTTPError`, with the status in `e.status_code`:

| Status | Meaning |
|--------|---------|
| 401 | The key is not accepted. The detail is `Invalid API key` for a wrong or revoked `sk-eden-...` key, `Custom token has expired.` for an expired one, and `Invalid token` for other token shapes. |
| 402 | Insufficient credit. |
| 403 | A compliance or guardrail rule refused the request. |
| 429 | Rate limit exceeded. |
| 451 | No provider of the model runs in a region that the endpoint you called, or your organization's [compliance policy](/v3/data-governance/compliance-policies), allows, or, for a [routing policy](/v3/llms/routing-policies), every target was dropped for its region. |

`ModelAPIError` is the parent class and also catches network failures, so keep it after `ModelHTTPError`.

<CodeGroup>
```python Python
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider
from pydantic_ai.exceptions import ModelAPIError, ModelHTTPError, UnexpectedModelBehavior

model = OpenAIChatModel(
    "openai/gpt-latest",
    provider=OpenAIProvider(
        api_key="YOUR_API_KEY",
        base_url="https://api.edenai.run/v3",
    ),
)
agent = Agent(model)

try:
    result = agent.run_sync("Hello!")
    print(result.output)
except ModelHTTPError as e:
    print(f"HTTP {e.status_code}: {e}")
except ModelAPIError as e:
    print(f"Could not reach the API: {e}")
except UnexpectedModelBehavior as e:
    print(f"Unexpected model behavior: {e}")
```
</CodeGroup>

```bash .env

```

import os
